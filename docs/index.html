Кодинг-агент, который работает с твоей моделью.

Подключаешь модель — а дальше агент сам читает, правит и запускает код в проекте, ищет по дереву и ведёт git. Перед изменениями спрашивает.

инструменты

Агент с инструментами, а не просто чат.

Он работает с проектом напрямую — файлы, шелл, поиск, git — и каждое изменение проходит через подтверждение, которое контролируешь ты.

Файлы и шелл

Читает, пишет и правит файлы, запускает шелл хоста, ищет по проекту через glob и grep.

Git как инструмент

Модель сама делает status, commit, push, pull и log — git это её инструмент.

Режимы доступа

Bypass, accept-edits или plan. Изменяющие действия ждут твоего подтверждения.

Откат

Коммиты агента становятся точками отката. Вернуть рабочее дерево и переписку к нужному моменту.

Память проекта

Заметки, привязанные к проекту, лежат обычными файлами и подхватываются в новых чатах.

Песочница

Запусти агента в одноразовой папке, не трогая реальный проект.
